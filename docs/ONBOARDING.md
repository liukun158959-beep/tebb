# 桌宠使用引导

关联 #189。首次缺少模型时进入「设置 → 模型与人设」，由带手势的圆点逐项指出 API 地址、模型 ID、API Key、保存和连通测试。所有输入、保存与测试都使用真正的设置页；引导没有另一份模型表单，也不写模型配置。

填齐字段不等于已保存，保存不等于连通；测试成功后修改地址、模型或 Key 会使本次测试标记失效。模型保存后允许明确选择稍后测试。未保存模型不能完成引导，但可以稍后继续和浏览其他页面。忙碌的保存、测试或连接期间，不离开当前引导步骤。

飞书和终端均为可跳过步骤。飞书带到真实连接页，以 tebb 的实际连接状态为准，不把系统已有登录当作连接成功。终端打开现有侧栏并定位真实沙箱自检区，不自动安装组件、不执行示例命令，失败继续显示在原页面。最终返回伙伴聊天。

「稍后继续」或 Escape 保存当前阶段；设置页的「继续使用引导」从阶段恢复，「从头重播引导」重新检查模型缺项。`onboarding.json` 版本 2 仅保存 `version/completed/step`，使用现有跨进程锁和原子写入，不保存字段内容、Key 或测试结果。未保存的表单只沿用当前窗口的页面保留，不承诺跨重启恢复；重启后连通状态仍需实际测试。已有配置不会被强制重新引导，旧版完成标记继续兼容。

圆点和小手属于引导专用呈现，不修改桌宠外观偏好和 Agent 人格。定位跟随实际字段、页面加载、滚动、缩放、窗口与侧栏尺寸；高亮层不拦截表单输入，用户可继续使用 Tab 和页面控件。提示区不是模态窗口，「指给我看」可重新定位并聚焦目标；缩小窗口时卡片可滚动，系统减少动态效果时停用跳动和位置过渡。
