# 个人使用中心

对应 #125，采用本批统一推荐授权。入口是“设置 → 个人使用”，支持近7天、近30天和全部记录，按模型条目/路由、项目、渠道筛选，查看每日趋势、模型汇总与关联编号，导出当前统计和已载入的元数据。

## 统计口径

- 主任务来自已有普通任务、伙伴整链和工作流记录。普通任务继续执行沿用原根；伙伴规划或单步 worker 成功不直接算整体成功；工作流 paused、waiting_approval、unknown 保留原状态。物理执行、诊断及失败/取消/超时分别查看。预算孤立 root 不会产生主任务。
- 模型调用指实际进入模型适配器的一次尝试，沿用原预算调用 UUID；直接连接测试独立记录。HTTP 尝试另计，可区分一次适配器调用中的网络重试。没有发送观测时明确显示未观测，不认作已发出或已计费。只有准入、没有实际观察的记录单列，不当作调用或零用量。
- 工具调用指通过外围检查、取得必要锁之后实际进入适配器的尝试。上层缓存命中、未执行的计划和前置拒绝不产生记录；适配器内返回拒绝、缓存、原回执、未知或异常另有状态。进入适配器不证明远端写入、命令或整个任务成功。实际 retry 各有 invocation ID，业务 operation_id 仍表示原业务操作。
- 模型调用返回或不完整响应的公开 partial 提供实际 token；缺失保留未知，已知零保留零。缓存 token 是输入的子集，不再加到总数；reasoning token 同样不重复加到输出。汇总展示已知部分及缺失次数。
- 费用按每次调用时用户配置的人民币普通输入/输出单价快照估算。未配置价格或用量不完整时费用未知；零价有效。缓存优惠未计算，估算不是供应商账单，也不会按当前单价重算历史。

任务按首次登记日期计，模型和工具按尝试时间计，均使用北京时间；不同日期跨越的任务与调用不能逐行相加。模型筛选只应用于模型用量；任务和工具仍按项目、渠道、日期查看。项目归属使用提交时快照，继续/分工沿用原目标；旧记录缺失的项目或渠道保留未知，不根据当前配置反推。渠道只是已保存的来源，不是消息发送成功数。

## 数据与兼容

`memory/usage-observations.sqlite3` 保存版本1的调用/工具元数据，不保存新增聊天正文、工具参数/输出、API Key 或 endpoint 原文；路由用摘要区分。配额仍由原 task_budgets Ledger 决定，统计不授予权限、不触发模型或自动重试。工具父调用关联由当前执行上下文保存，不使用跨任务的全局最新调用。

旧 `usage.jsonl` 保持原样和旧 load_usage 兼容，界面单列“历史用量汇总”。旧行可能是整轮汇总或单响应，条数不等于对话、任务或精确调用次数；与上方新观察不相加，不套用无法还原的项目/渠道/路由筛选。损坏行显示读取未完成，保留文件，不打印原行或自动删除。暂不自动清理历史数据。

暂停调用调试的“详细载荷”只暂停原始正文追踪，本机次数与用量元数据继续记录。前端说明此区别。查询是只读的，运行中的 AI 不阻止读取；字段、错误、加载和未确认复用共享控件，切换筛选保留旧结果并标注，过期响应不覆盖新结果，隐藏页不轮询。

## AI 调试入口

认证 RPC：`load_personal_usage(filters={}, cursor='', limit=50)`；limit 为1到200。filters 只允许 period（7/30/all）、model、project、channel、kind。model 为返回的模型条目/路由 key；project/channel 使用 options 返回的 key，`*` 表示全部。kind 支持 all/model/tool/task/physical/diagnostic。响应包含总量、每日与模型汇总、分页元数据及历史质量说明。

游标使用开始时间和稳定 ID，固定原查询的截止时间并校验筛选；同时间记录不会漏页，筛选变化须从第一页开始。状态反映当前业务记录，不是历史状态快照。单次元数据读取有明确上限，超限或损坏返回错误，不静默截断后冒充完整统计。查询不接受任意数据库或文件路径。
