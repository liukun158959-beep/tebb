# tebb v0.4.0 · 把计划，变成成果

这次更新把事项、日程、伙伴执行与研究成果接进同一个工作区，同时完成后台服务解耦。

## 新增与改进

- **事项与日程**：四列事项看板支持拖动、归档、项目归属和明确的 AI 执行。日程提供月／周／日与完整 24 小时时间轴，重叠日程并排、双击空白新建草稿、长按抬起后拖动或调整时长。草稿未保存直接取消。
- **本地保存与飞书同步**：新日程默认本地，可单条或确认清单后批量同步到飞书。已同步日程调整时间会更新远端；失败、冲突与结果未确认分别提示，先核对后继续。事项与日程支持双向定位，排期不会自动改变事项进度。
- **tebb 与职责伙伴**：默认通用助手按需委派研究、写作、编程或图表伙伴，保留直接聊天；目标不清先提问，聊天内选项卡与全局“待你处理”可继续原任务。新增一次／每天／每周交给 tebb 的自动化，执行与失败阶段可追踪。
- **搜索与报告**：搜索服务独立于模型地址，支持渠道诊断与备用；公开网页安全读取、长文按区间／关键词续读。报告内嵌随主题的柱状图、折线图、时间线及多种流程布局；图表助手按需调用，共享参数预检、最多两轮定向修正与成功成果复用。修复图表闪烁、无效请求耗尽构建额度及超时后成果丢失。
- **上下文与记忆**：输入框下打开实际请求与参数侧栏，伙伴记忆独立弹窗。支持为模型配置窗口与输出预留，使用服务 usage 或明确配置的真实 tokenizer；未知容量和不可用统计如实显示。
- **工作区与后台**：带文字分组导航、独立日程、三栏笔记与阅读弹窗、桌宠独立外观页；后台不再继承旧 GUI。配置、笔记、知识库、日程与自动化共用业务服务，补齐认证 RPC、单运行实例、阶段诊断、并发保护和恢复回执。

## 使用与更新

1. 下载 `tebb-0.4.0-windows-x64.zip`，完整解压到独立目录。
2. 退出旧版，运行 `tebb.exe`，保留同目录的 `runtime` 文件夹。用户配置与记录沿用 `%LOCALAPPDATA%/DeskCompanion`；建议更新前备份该目录。
3. 首次启动填写自己的模型 API 地址、模型 ID 与 API Key，再测试连接。工具执行需要模型支持 tool calling。

支持 Windows 10/11 x64，需要 WebView2 Runtime。包内含独立 Python，无需另装 Node、Rust 或 Python。没有安装器、自动更新器和代码签名。

Live2D 形象、Core、个人权重、密钥与历史不随包分发；默认可用圆形桌宠。知识库向量模型及扩展按使用说明另行安装。飞书需用户自己的授权，搜索公共渠道仍可能限流；已同步日程仅在能够核实权限及参与人的普通个人日程范围内编辑，多人、全天、重复等继续只读。真实 tokenizer 需要相应模型分词配置；本版没有新增统一执行上下文自动压缩策略。
