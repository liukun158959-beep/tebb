# tebb v0.4.1 · 让对话，更清晰

发布候选准备稿，尚未正式发布。正式下载仍以 GitHub 最新 Release 为准；候选构建与验收结果记录在 [#181](https://github.com/liukun158959-beep/tebb/issues/181)。

## 新增与修复

- **一个新对话入口**：伙伴聊天采用可折叠项目树，项目内外使用统一紧凑行。顶部“新对话”选择 tebb、职责伙伴或协作群，并明确项目归属；文件夹与整理操作收进管理菜单。
- **先留草稿，发送再入列**：普通新对话在首次发送时才保存会话。重复点击新建、暂时切页或返回对话后可继续当前窗口中的草稿；明确放弃才清除。会话与首条消息原子保存，回执断连先读取核对，不自动重复提交。已有空会话和重名群聊保留，协作群仍按明确创建保存；草稿不承诺跨窗口关闭恢复。
- **回复连贯，状态如实**：修复流式正文被后续刷新覆盖而消失的问题，保留已取得的片段和真实完成状态，隐藏内部控制文本。未完整完成不会显示成成功。
- **飞书明确连接**：每份用户数据目录需要明确连接飞书后才读取日程等外部数据，不因本机已有 lark-cli 登录直接展示个人内容。升级后如需继续使用飞书，请在连接页面核对账号并连接；断开产品连接不退出系统已有登录，不删除原有本地记录。
- **等待与退出**：待命阶段预加载模型 SDK，减少首次任务的可避免启动开销；退出时有限等待飞书消息线程收尾。具体模型网络与生成速度仍取决于服务和任务，不宣称真实模型加速比例。
- **构建可核对**：前端、Python／固定 Atlas 和 Rust 独立回归；手动候选绑定通过检查的不可变提交，复用运行时、打包审计、空白配置与迁移检查。普通提交不自动正式发布。
- **明确开源授权**：tebb 与 Atlas 自有代码采用 MIT；补齐上游改编内容、前端和 Rust 依赖声明，保留 Python、字体原许可，候选包附 LICENSE 与实际依赖许可清单。第三方内容继续按原授权分发。

## 使用与升级

候选为 Windows 10/11 x64 便携 ZIP，需要 WebView2 Runtime。完整解压后运行 tebb.exe，同目录 runtime 必须保留。包内含独立 Python，无需另装 Node、Rust 或 Python。

升级先退出旧版，建议备份 %LOCALAPPDATA%/DeskCompanion，再更换程序目录；已有模型、会话和事项按原数据目录保留。全新用户从空白配置引导开始，需填写自己的模型地址、模型 ID 和密钥。模型需支持工具调用才能执行相应工具。

默认圆形桌宠可直接使用；个人 Live2D／Core、权重、配置、密钥、历史和日志不随包分发。知识库扩展按需准备，搜索公共渠道仍可能限流。本候选没有安装器、自动更新器或代码签名；#174 Windows 安装版和 #173 任务质量 eval 另行推进。

## 验收与限制

侧栏已通过真实浏览器与认证 WebSocket 回归，模拟了首发提交成功但回执丢失，检查恢复草稿、首次发送、项目归属和群聊兼容。使用隔离数据和假模型／飞书，不向真实飞书发送测试写入。

候选的具体提交、CI 结果、ZIP 校验和、空白／升级与原生窗口检查分别记录在 #181。浏览器验证不能替代原生窗口检查，条件跳过不能算作通过；没有用自动复跑掩盖失败，也未重放旧失败任务。
