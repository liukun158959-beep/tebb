# 文件夹项目

项目以本机文件夹为基础。选择「项目 → 打开文件夹」创建或进入项目；名称默认取文件夹名，可单独改名。同一路径重复打开会复用项目。已有的聊天分类可在项目设置中绑定文件夹。

每个项目分别保存主目录、只读参考目录、文件编辑和本地命令权限。新目录默认只读，代码目录和权限从顶部文件夹入口配置。切换项目会切换文件预览与之后提交任务的目录；执行中的任务保留原项目目录快照，修改授权后旧快照失效。无项目的独立聊天不继承其他项目的文件权限。

知识库的[资料工作区](MATERIALS.md)另行登记可检索的来源和正文版本。旧全局索引不自动归入项目，项目检索不回退全局；来源位置改变用明确重新定位，移除索引保留原文件和历史版本。

项目说明适用于本项目后续任务。收藏成功的回答会同时保存到项目资料，项目设置中可移除共享；全文笔记保留在知识库。注入上下文只取最近六份资料的有界节选，不自动拼接所有聊天。伙伴可通过 `project_chat_search` 按关键词读取本项目其他聊天的片段，返回会话来源，不能跨项目检索。

## 整理旧对话

侧栏的「整理已有对话」先展示实际任务目录的归类建议：

- 路径明确且目录可用：可勾选归类。
- 记录过多个目录：由用户手动选择项目。
- 无目录、目录失效、任务运行中：保留现状。
- 已归入对应文件夹项目：不重复迁移。

预览不修改历史。确认时再次核对预览依据；数据变化则要求重新预览。归类不会复制、移动或删除源文件，新增的项目也不继承过去的编辑／命令权限。

目录记录只证明任务当时绑定过这个目录，不能证明聊天讨论的对象就是该文件夹。例如，联网分析 GitHub 仓库的任务可能沿用了旧全局目录，仍需逐项核对。

项目归属改变前须等待会话任务结束。动作与其返回的状态快照保持在同一协作锁内，避免其他窗口切换会话时返回错误的选中会话。

## 参考与区别

OpenAI 官方说明中的本地项目可以连接一个或多个文件夹，并指定主文件夹；同一项目中的聊天仍分别保留记录：

https://learn.chatgpt.com/docs/projects

tebb 采用已确认的「一个可编辑主目录＋只读参考目录」约定；共享项目资料，其他聊天按需检索。以上是 tebb 的实现选择，不表示与 ChatGPT 的全部权限、记忆或界面行为相同。
