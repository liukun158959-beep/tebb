# tebb 数据目录与飞书连接

#178 排查发现：程序目录、tebb 用户数据目录、lark-cli 本机登录是三种不同状态。

- 便携 ZIP 是程序与运行时；重新下载或换解压目录，不会自动清空用户目录。
- 发布版沿用 %LOCALAPPDATA%/DeskCompanion。旧配置、会话、本地日程及远端缓存保留；源码版使用自己的数据目录。
- lark-cli 的登录属于操作系统用户，不随 DESK_COMPANION_DATA_DIR 自动隔离。旧版日程刷新会直接调用它，所以空的 tebb 数据目录也可能读取本机已登录账户的日程。这不能直接证明 ZIP 包内夹带日程。

## 本次规则

个人账户的数据访问必须在当前 tebb 数据目录明确连接；状态保存于 feishu-connection.json，不包含凭据。不把系统已登录自动当作 tebb 已连接。

设置 → 连接与网络 → 飞书会区分“检测到本机登录”和“已连接”。已有登录可点“连接本机账户”；否则打开网页登录，完成后登记连接。断开只撤销此 tebb 的连接，不退出系统 lark-cli，不删除历史、本地日程、缓存或其他软件的登录。旧数据目录升级后也需明确连接一次；保留数据不等于自动批准外部查询。

未连接时，个人账户的数据命令在启动 CLI 前被拒绝；日程仍可本地保存，远端读取明确提示未连接，不能伪报远端没有安排。旧缓存按原数据保留，不能当作刚刚重新核对的结果。已明确配置的机器人身份、CLI 身份/配置查询与个人账户连接分开，不要求机器人重新完成个人授权。
