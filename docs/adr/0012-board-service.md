# 今日看板使用独立操作资源与分区合并

今日看板的加载、创建日程、删除日程和删除待办使用独立 BoardService，复用 board_data 的解析与飞书调用；共同底层为 RPC、聊天工具、桌宠和自动化提供相同的非阻塞操作准入。当天缓存命中不等待远端操作，模型忙碌不阻止看板；飞书等待不持宿主、全局或存储锁。这个边界允许模型与看板并行，但无缓存的自动化/跨日加载遇到更新时会立即报告忙碌而不排队。见 #132。

所有 today.json 写入者通过短时跨进程锁读改写、原子替换，提交时合并最新分区并保留摘要、摘要时间和文档链接；跨午夜的旧请求不得覆盖新一天，换日不继承昨日摘要或链接。保留真实飞书删除及日程删除通知，远端修改、查询、缓存写入分阶段报告；远端结果未知先核对，已完成不能据后续错误重做。保持同步 RPC 和正常结构，不新增任务/取消/自动重试；断连不代表取消。前端消费业务成功字段，失败保留输入及原看板，避免误报创建成功。
