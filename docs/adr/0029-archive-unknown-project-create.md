# 归档未知创建不等于停止沙箱

#203保留原unknown操作、owner、请求映射、诊断及迟到UUID，仅在用户明确放弃后释放应用准入。首版限unknown prepare、未绑定UUID、没有服务；不根据清单空缺、时间、模型worker退出或PID判断远端不存在，也不自动create/stop。

复用ResourceLock的OS文件锁标明父服务原prepare调用的实际运行权，覆盖准入后的create/配置/成功或失败收尾；显式候选归属验证也与归档串行。Store在同一事务内核对预期原操作并写独立归档回执，保留原unknown，不删除日志。原请求重放仍返回旧记录，新编号可另建；迟到身份仅绑定旧记录，迟到finish不得覆盖unknown或重新占位。

桌面认证项目RPC和现有项目运行面板提供说明、确认、稳定请求编号及状态/日志查询；模型不新增自动归档权限。操作归档后日志可在无本地写者时结束轮询，创建结果未知单独呈现。代价是可能仍有未观察到的远端资源，后续只能按原身份核对，不能假报已停止。

验证两次未知占位、仍活跃创建、迟到ID/finish、同仓新请求、重放、重启、错误owner/已知ID和服务；原故障不重采样、不重启daemon。原生检查只预定只读inventory及隔离本地回执，不操作旧unknown实例。
