# 手动压缩采用短暂预留与分阶段保存

手动压缩仍是返回记忆页快照的同步 RPC，由 ContextCompressionService 组合 ChatSessionService，复用 ConversationService 的模型调用、用量及 context_pack 的压缩算法和存储，旧 App 仅保留兼容入口。按用户确认，本批不改成异步任务或增加取消入口，断连不取消后台执行，也不自动重试，用户重连后读取记忆页核对。

整轮持有会话修改保护会长占任务条件锁、会话锁和共享写锁，阻塞其他会话与只读请求，因此开始时短暂固定选择、检查已有任务并登记会话预留和共享助手忙碌状态，等待模型时释放锁，保存时才获取 WRITES。TaskManager 的 reserve_session 与提交、调度及修改保护共用条件锁登记预留；当前会话的新任务及共享状态修改被拒绝，其他会话任务、查询和取消继续，结束或失败后释放。宿主锁也只用于短暂的开始/模型绑定，已有宿主操作占用时立即拒绝。

仅正常完成、非空且无工具调用的文本可写摘要，原文不删除，自动压缩复用相同结果校验。模型成功回执先沿用原用量记录，再保存摘要；失败按 not_changed、unconfirmed、committed 区分未替换、保存结果未确认、已保存但后续读取或清理失败，不把调用费用、文件提交和页面刷新声称为同一事务。
