# 知识库管理使用独立服务与计算后提交

知识库八个现有 RPC 统一由 KnowledgeService 管理共享助手准入和错误回执；Bridge 直接调用服务，旧 App 保留薄转发。设置和索引复用 ResourceLock 短时跨进程保护与现有原子替换，入库、重建及检索固定设置/索引快照，长计算不持宿主、全局或存储锁；提交时复验两份快照，变化则拒绝覆盖。这个取舍允许独立任务和读取继续，但并发修改后需要用户核对并手动重试，保留同步协议而不引入持久化任务。设置修改不自动重建，旧索引保留且检索明确要求重建；删除来源仅移出索引。见 #131。

模型资源按仓库名使用跨进程共享使用锁及排他修改锁，均非阻塞准入；下载和删除与加载/推理冲突时立即拒绝，兼容读取及其他模型可继续。缓存以模型文件元数据识别外部替换，下载工作线程拥有修改锁直到收尾，共享助手只在启动阶段预留；保留内存进度、临时分片与手动续传，不增加进程退出后的自动恢复或取消协议。同步试问复用 Atlas 完成校验、产品纯文本校验和原用量顺序，不写对话历史；错误保留已取得正文和实际阶段。写入未确认、已完成但刷新失败、模型部分删除分别报告，断连不取消操作且不得盲重试。
