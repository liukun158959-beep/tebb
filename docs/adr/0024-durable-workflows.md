# 工作流版本与节点回执独立保存，执行复用现有任务进程

#188 用户确认以原子能力画布组合自动化，保留旧作业且断连不重复外部写入。工作流定义、不可变版本与节点回执由独立 SQLite 存储拥有，认证 RPC 和原调度仅作准入与观察，模型与网络等待不持有存储事务或宿主全局锁；执行交给现有 TaskManager 独立进程，避免再建后台执行基础设施。

每轮固定版本和稳定节点标识，写入前落盘 pending，写入成功但回执不完整或进程终止时保留 unknown，核对原目标后续跑原执行。代价是未知写入需要人工提供原文档／消息编号，不能通过自动重试取得“成功”；这比把图序列重新执行或假设远端失败更能保留真实外部事实。画布采用 React Flow，不把前端图形状态作为执行事实。
