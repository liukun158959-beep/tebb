# 记忆编辑区分全局事实与单会话历史

记忆页的 4 个编辑入口由 MemoryEditingService 组合 ChatSessionService，Bridge 直接调用，旧 App 仅保留兼容方法；选中会话、助手状态、存储及任务保护仍由现有模块拥有，不复制状态或另建事务层。手动压缩涉及模型执行，继续留待后续拆分。

按用户确认，长期事实编辑仅在共享助手回复期间拒绝，独立后台任务运行期间仍允许，沿用 WRITES 与事实存储锁串行写入；这保留现有并发能力，但已开始的回复可能持有旧事实，任务记忆工具也可能随后更新事实。单句历史删除则复用会话选择锁与任务收尾保护，当前会话未结束时拒绝删除，其他会话继续；锁顺序为 WRITES、会话选择锁、任务条件锁。

历史删除先验证匹配存在，再使包含该句的摘要失效，最后删除所有同角色、同正文的重复原文并清理临时上下文，避免摘要失败时原文已被删除。未覆盖该句的摘要保留；失败沿用 change_state 报告未修改、结果未确认、部分完成或已更新但刷新失败，不承诺跨文件回滚。
