# 模型传输复用 Atlas，协作流程留在产品

传统 Agent 和独立协作 worker 原先分别维护 SDK 流解析与手写 HTTP/SSE，已出现完成判定差异。两条路径统一复用 `atlas.llm` 的请求配置、响应聚合、严格完成校验和回调契约，协作 worker 仍自行拥有工具调度、权限、预算、交付校验及任务进程取消。GLM reasoning 回传、route 低思考、代理与 UI 事件转换由产品适配器配置，不进入通用内核。这样无需改写协作执行循环，也能由同一套行为测试约束两条模型路径；代价是协作 worker 同样依赖正式 Atlas 包，发布必须同步固定提交，不再应用工作区采样补丁。
