# 笔记问答与勾选总结复用笔记服务生命周期

笔记问答与勾选总结由 NotebookService 管理，复用已有共享助手准入、ConversationService 模型绑定和用量记录、Atlas 完成校验、笔记存储及系统启动适配器。宿主只保留兼容调用，流式传输层直接调用服务；模型和系统等待不持宿主、笔记或全局写锁，忙碌立即拒绝，不再排队后执行。问答保持 token/status/done/error 协议，总结保持同步 RPC；本批不任务化或增加取消。见 #130。

问答继续先保存提问再检索，因此检索失败也可能留下提问；不把失败片段持久化为完整回答。只有 Atlas 正常完成、无工具调用的非空字符串才保存完整回答/新笔记，用量仍先于产品正文校验和保存记录。用量或后续保存失败时回执保留已取得正文及阶段，不声称未计费或已回滚；总结保存、文件导出和打开分阶段报告已确认结果，不重跑模型。连接断开只结束前端等待，后台可能继续保存/打开；需重新读取核对，无法通过原请求恢复未持久化片段。这个限制避免在本批引入任务、取消和幂等存储协议。
