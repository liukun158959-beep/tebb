# 安装程序替换运行时，用户扩展按兼容版本保留

#174采用本批统一推荐授权。NSIS与便携包共用受审计的程序和固定运行时，安装不改变原用户数据根；内置依赖随版本替换，知识库扩展移到用户目录，并按Python ABI及基础依赖指纹分层。这样升级不再依赖保留旧runtime中的任意文件，也不会把不同基础版本的扩展混用；旧便携版配置沿用，旧runtime内的扩展需明确重装一次，原文件不自动迁移或删除。

安装和卸载同时检查前台程序及原后台运行权，后台仍在收尾时拒绝替换。升级和静默卸载不清用户数据；交互卸载默认保留，明确选择清除才处理约定的应用数据根，预先拒绝重解析点与越界路径。外部项目、系统登录和Docker环境不属于安装器的数据所有权；清理未完成必须保留具体阶段结果。

实际验收发现NSIS普通卸载启动器会先于临时卸载副本退出，只根据启动器或文件瞬时缺失等待不足以支持立即重装。产品hooks因此以应用标识派生的会话级命名互斥量串行保护实际文件阶段，保持到进程退出；验证入口采用官方复制卸载器后以末尾 `_?=` 指定原目录的同步调用方式，另以真实并发安装验证拒绝。保留原失败报告，不以重试覆盖失败。
