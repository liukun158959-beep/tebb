# 0021：同一主任务拥有目标核对、分工与最终交付

2026-10-28 用户 Q3、Q5 确认，关联 #154；取代 ADR0020 中“可分给自身、额外创建最终 tebb 任务”的部分。强制规划、自我委派与独立汇总会把简单或模糊目标变成多轮空转，因此先在无业务工具的阶段确认目标：不明确则持久保留“待补充”，释放模型名额；补充后继续原主任务，而非创建替代任务。

明确简单目标由负责人在原任务执行；仅独立职责工作生成一层其他伙伴子任务，负责人在原任务汇总。保留队列、项目授权与取消传播，阶段用各自调用预算，整链调用数与结果另作公开投影；旧图不改写历史，子节点成功不等于整体完成。自动化等待目标时不重派，重启后观察原记录；事项进度仍由用户决定。
