# 资料来源与索引版本分别管理

状态：接受。关联：#122。用户已授权本批需求全部采用推荐方案。

已有附件是不可变快照，知识库重建却重新读取保存路径。将快照编号直接当持续来源身份，会让移动、改名和刷新后的引用含义混淆。历史全局索引也没有项目授权含义，不能因为当前打开项目而自动迁入。

来源登记负责稳定编号、当前位置、所属范围、观察版本、核对时间及操作状态；附件快照保持原义。来源正文版本不可变，索引负责引用实际版本的片段与向量。移除索引保留来源及历史快照，重新定位不移动用户文件。

手动检查和单来源刷新先读取明确授权的来源，再计算派生索引；失败或取消保留旧索引。提交时先锁定来源登记并复验版本/授权，再使用既有索引CAS提交，锁顺序为来源到索引，不在读取和嵌入期间持锁。索引状态从索引派生，不在登记中复制另一份可变索引事实。

历史索引保留旧全局范围、原编号和未知新鲜度。新项目资料由后端隔离，当前项目查询不回退全局；目录授权变化后重新核对。引用展示历史片段，查看当前来源另行验证权限，未知历史版本不补造。

代价是增加来源登记及正文版本存储；它提供索引删除后仍稳定的身份和刷新失败可解释性。把全部状态塞入附件或索引会更短，但混淆所有权并迫使已有历史引用改变含义。首版不做全盘扫描、自动同步、原文件删除或替换向量数据库。
