# 同一用户目标共用任务预算

#170由产品任务域持有一份跨进程预算，调度器绑定根目标、分工和继续关系；实际模型发送/工具执行前原子准入，任务事件与界面只读取投影。选择复用SQLite、现有任务监督和Atlas公开传输接口，避免事后计数在并行时超发，也避免把吞掉插件异常的回调当权限边界。

预留收尾，按简单/研究/编码/图表/澄清设有限档位；仅真实新进展允许一次预定幅度扩展，用户硬期限仍约束。未知输入分词、用量或价格保持未知；只有已绑定模型/路由的输出参数才声明可请求硬输出上限，截断的partial不会被执行成完整结果。旧数据不反推消耗，原未知写入和常驻预览所有权不改变。

详见[任务预算与验证](../TASK_BUDGETS.md)。
