# 本地日程保留稳定身份，飞书同步作为显式发布

已采纳，2026-10-28；对应 #141。用户需要未连接飞书时仍能安排时间，保存后可选择同步。日程不再全部以飞书为唯一事实来源：LocalCalendarService 管本地记录，独立 remote 映射承接同步后的飞书内容，保留本地身份与事项关系。合并投影消除双份显示，复用 SQLite、SchedulingService、认证 RPC 和远端改期。这样增加来源合并职责，但避免同步时迁移身份、事项引用，或让离线安排依赖飞书。

同步不能假设超时等于未创建。沿用持久阶段回执，冻结条目版本及目标身份，创建前登记编号；不明结果只允许明确核对绑定或确认未创建，不自动重放，不反向删除成功项。用户明确要求本地默认，因此不采用所有保存直接写飞书，也不扩展任意类型日程的编辑权限。规则与接口见 [日程](../CALENDAR.md)。
