# V44：侧边栏自动化任务（复盘 / 方舟子界面 + 定时）

> 历史规格，游戏动作已移除；当前自动化生命周期与并发规则见 [开发指南](DEVELOPMENT.md) 和 [ADR 0014](adr/0014-automation-runtime.md)。本文件保留当时的取舍，不覆盖当前 AGENTS.md 的测试约定。

> 2026-09-03。GitHub #19。grill-me 五轮已对齐。开工前只写本规格。

## 0. 问题

**When** 作者打开看板，要管会到点自己跑的事（周日复盘、夜里清日常），也还要能手点  
**I want** 侧边栏一个「自动化任务」：默认看已建定时；周复盘和明日方舟是操作台；能从封闭动作表新建、改、停，并立刻跑一次验收  
**so I can** 不用在对话复盘和方舟顶栏之间找入口，也不用每周/每天坐在电脑前点

现状替代：对话子界面手点生成/写入；「明日方舟」侧栏手点清日常；Windows 里 `DeskCompanion.ArknightsPC` / `MAA` / `Stop` 只是提升权限，不是用户作业。

## 1. 非目标

- 任意 skill / CLI / 自由指令（插件市场）。
- 飞书 / 妙搭云端触发、五段 cron、每 N 分钟。
- 关机或没开桌宠的补跑；队列写盘。
- 定时新建飞书文档；每条定时自己存一份勾选。
- 开工 #8（不代开 exe）、V25 活动/企鹅、#9、#10。
- 把三条 `DeskCompanion.*` 提升任务列进用户任务列表。
- 到点自动喊凯尔希。
- 不另起 `python --run-job` 第二进程。

## 2. Must（≤3）

1. **导航。** 侧边栏「明日方舟」改为「自动化任务」。子界面：任务列表（默认）/ 周复盘 / 明日方舟。复盘从对话迁走；今日页仍只读已落盘正文。
2. **定时是真的。** 封闭三动作（生成复盘、覆盖写入飞书、清日常）；每天或每周（可多选星期）+ 本地时刻；桌宠进程在才跑；能新建 / 改 / 停用 / 删除。
3. **到点看得见。** 调现有函数；忙则本次进程内存排队（同类合并、同分钟固定顺序）；错过不补跑；失败或错过侧边栏标红；每行可立刻执行。

## 3. 拍板

| 项 | 选择 |
|----|------|
| 列表 | 只出现已创建的定时。空态引导去「周复盘 / 明日方舟」手点，或点新建 |
| 运行时 | 托盘进程内。挂在现有 `on_pet_tick`，内部节流（约 15s 扫一次），禁止 16ms 写盘或跑 LLM |
| 写入飞书（定时） | 只覆盖配置时绑死的 url/token；没绑不能保存。手点复盘页仍可覆盖或填标题新建 |
| 清日常 | 到点走现有 `maa_job` 整条（含现在的代开启动器 / 计划任务，UAC 与手点相同）。勾选读当前那一份 |
| 错过 | 不补跑。用 `last_alive_at` 心跳判断「本该跑的时候进程不在」 |
| 排队 | 仅内存。退出丢掉。`retro_gen` / `retro_write` / `maa_daily` 各最多一条在队或在跑 |
| 同分钟顺序 | 生成复盘 → 写入飞书 → 清日常 |
| 忙碌 | `_agent_running` 或 `pet.busy`。忙则入队，不打断 |
| 标红 | 失败或错过；进过任务列表视为看过（红点消，文案仍在）；下次成功也消 |
| 立刻执行 | 每行一按钮，走同一执行器和排队 |
| 星期 | `datetime.weekday()`：周一=0 … 周日=6。一条每周可勾多天，时刻相同 |
| 名称 | 必填、本机任务间唯一 |

## 4. 落盘

文件：项目根 `automation_jobs.json`（与 `maa.json` 同级），**gitignore**。

没有文件 = 零条任务，不报错、不发明任务。有文件则根对象必须有 `jobs`（数组）和 `last_alive_at`（字符串，可空）。某条缺必填 → 整份加载失败，原文指出路径和缺键，改正或删文件；禁止跳过坏行继续。

每条 job 必填：

| 键 | 约束 |
|----|------|
| `id` | 非空字符串，创建时生成，不可改 |
| `name` | 非空，与其它 job 不重名 |
| `action` | `retro_gen` / `retro_write` / `maa_daily` |
| `enabled` | bool |
| `cadence` | `daily` / `weekly` |
| `weekdays` | 整数数组。`daily` 必须 `[]`；`weekly` 必须非空，元素 ∈ 0..6、去重 |
| `hour` | 0..23 整数 |
| `minute` | 0..59 整数 |
| `doc` | 字符串。`retro_write` 必须非空 url 或 token；其它动作必须 `""` |
| `created_at` | 本地 ISO 时间，创建后不可改 |
| `last_run_slot` | 字符串，已执行或已记错过的槽，如 `2026-09-07T21:00`；从未跑过为 `""` |
| `last_result` | `""` / `ok` / `fail` / `missed` / `queued` |
| `last_error` | 字符串，成功时 `""` |
| `alert_seen` | bool。失败/错过写入后为 false；打开任务列表后对该条置 true |

心跳：进程在时大约每 60s 把 `last_alive_at` 写成此刻本地 ISO。首次没有心跳则启动不记错过。

错过：对每条 `enabled` 且 `created_at` 早于该槽的任务，若在 `(last_alive_at, now]` 内存在应跑槽，且 `last_run_slot` 不是该槽 → `last_result=missed`，`alert_seen=false`，**不执行**。刚创建且今日时刻已过：下一槽是明天/下个勾选日，不记今天错过。

## 5. 执行

| `action` | 调用 | 失败 |
|----|------|------|
| `retro_gen` | 现有 `generate_week_review`（`weekly-retro`，不带工具） | 没模型 / GitHub / 飞书材料失败 → 原文。不偷写半篇 |
| `retro_write` | `overwrite_markdown_doc(job.doc, today.summary)` | 没有本周复盘正文 → 失败「先生成或配一条更早的生成」，不偷生成、不 `+create` |
| `maa_daily` | 现有开始清日常入口（同一份 `selected`） | 与手点相同（含可能的 UAC） |

立刻执行：把该 `id` 按 action 合并进内存队列（已有同类则仍一条），再按第 3 节顺序尝试开跑。

看板桥（`board_workbench` / `bridge`）只暴露：列出、创建、更新、停用、删除、立刻执行、打开列表（消红）。禁止在 HTML 里拼 schtasks。

## 6. 界面

- 侧边栏工作区：今日、对话、**自动化任务**、GitHub、飞书。设置区不变。自动化入口 `id` 便于标红（复用日志 `.tab.alert`）。
- 自动化子导航：任务 / 周复盘 / 明日方舟。默认任务。
- 任务页：空态文案 + 新建。表单：名称、动作、每天或每周（星期勾选）、时刻；动作是写入时必选已获取的文档（与复盘页同一套 `list_feishu_docs`）。行上：摘要、上次结果、启用、立刻执行、编辑、删除。
- 周复盘：从对话整块迁入（生成 / 获取文档 / 写入 / 标题新建）。对话子导航去掉「复盘」。
- 明日方舟：现 `panel-maa` 整页挪成子界面，不改森空岛 / 刷什么 / 勾选 / 路径按钮。
- 今日页提示改为指向「自动化任务 → 周复盘」。合同与技能文案同步：用户要周报时去该子界面，不要说对话复盘。

## 7. 验收

- Given 打开看板，When 看工作区导航，Then 没有与今日平级的「明日方舟」；对话子导航没有「复盘」。
- Given 还没有定时，When 打开自动化任务，Then 空态能看见引导；不是两条未定时的目录卡。
- Given 新建「每周日 21:00 生成复盘」并立刻执行，When 成功，Then 周复盘子界面和今日只读区出现正文；`last_result=ok`。
- Given 写入定时没填 `doc`，When 保存，Then 失败原文，文件不出现这条。
- Given 绑了 wiki/docx url 的写入定时，When 立刻执行且已有复盘正文，Then 该文档被 markdown 整篇覆盖，不另建。
- Given 清日常定时立刻执行，When 发出，Then 走现有长草线程，勾选与看板/气泡一致。
- Given 生成复盘仍在跑时清日常到点，When 时钟扫到，Then 清日常进队且列表为排队中，不打断生成；队列里不会出现两趟清日常。
- Given 周日 21:00 同时配了生成和写入，When 到点且空闲，Then 先生成再写入。
- Given 关掉桌宠，过了某条已启用任务的时刻再开，When 启动完成，Then 该次 `missed`、侧边栏红、不自动跑。进入任务列表后红点消，错过文案仍在。
- Given 手点周复盘填标题新建，When 写入，Then 仍走 `docs +create`（仅定时禁止新建）。

## 8. AI 失败

- 没接模型 → 生成失败，去侧边栏「模型」。
- 飞书未登录或没有 docs → 搜索/写入失败，去「飞书」登录。
- 只配了写入、没有本周 `summary` → 写入失败原文，不偷生成。
- 清日常到点弹 UAC → 与手点相同，本刀不修；失败写进 `last_error`。
- `automation_jobs.json` 坏了 → 启动或打开列表失败可见，不静默当空列表。

## 9. 最危险假设

1. 夜里清日常仍可能弹 UAC（沿用现实现）。验证：本刀不改开游戏路径。
2. 心跳间隔过大把「进程一直在」误判错过。验证：60s 心跳；进程内正常跑过的槽只记 `ok`/`fail`，不记 `missed`。
3. 排队在内存：长对话结束突然开始清日常。验证：列表显示排队中；退出桌宠则队列丢弃且不当补跑。
4. 任务列表做成任意命令框。验证：动作只有三选一。
