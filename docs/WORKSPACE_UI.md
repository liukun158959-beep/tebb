## 页面与状态所有权

- 主导航提供伙伴聊天、AI 执行、自动化、事项、日程、笔记、知识库、视频与飞书；顶部只保留当前对话及项目工具。沿用伙伴聊天作为默认首页。
- 日程工作区负责周／单日的展示与事件定位；LocalCalendarService 拥有本地安排与显式同步，SchedulingService 负责合并、权限检查、改期和回执，BoardService 保留既有飞书待办/删除兼容。事项、聊天和桌宠可以定位到同一日程页。
- 事项仍由 WorkBoardController 拥有四列进度，日程调整不修改事项或 AI 状态。FullCalendar 原有拖动、边缘缩放、15 分钟吸附、Escape、键盘和未确认核对继续有效；不扩大可编辑事件范围。
- 笔记会话与已存笔记沿用既有定义。三栏保留来源选择与问答；阅读弹窗不替换问答 DOM，关闭后保留输入、滚动和焦点。就地添加复用知识库入库与本地资料选择，取消勾选不删除来源。
- 知识库按资料库、检索检查、索引设置分区；修改索引与模型仍执行现有规则。设置与连接状态不混入今天的日常工作列表。

## 兼容与失败

继续保留旧入口的后台服务与开发者调试，不删除用于页面状态保留的隐藏组件。删除永久不显示的旧侧栏。没有真实数据时显示空态或读取错误，不用示例任务或提醒填充正式页面。操作失败保留输入和实际阶段，不自动重复飞书写入。

飞书待办本批保留既有查看/删除语义；预览里的本地勾选没有对应的完成 RPC，不能把删除伪装成完成，也不在界面改版中默认实现 #9。伙伴当前扩展工具只提供日程查询；聊天中的日程入口从真实 `get_today_agenda` 工具记录产生，不解析模型“已创建”正文，更不因此增加创建权限。独立新建复用既有 `create_agenda`；关联事项时复用带操作编号的 `change_schedule`。
